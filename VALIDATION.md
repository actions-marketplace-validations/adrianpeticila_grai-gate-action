# grai-gate validation v2

Date: 2026-11-05
Engine: 0.1.7

## What this is

A small labeled corpus test of the shipped engine. It measures how often the gate flags model-generated markdown and how often it flags human-edited markdown. It is a style check, not an authorship detector.

## Corpus

- 58 human-edited markdown docs
- 63 model-generated markdown docs
- 121 files total
- 5 files had too few sentences for CV

The source docs are private. File names are redacted to protect the source repositories. The human label means human-edited, not guaranteed human-only. The model label means generated by a model from a prompt or a rewrite. This is a seed corpus, not a benchmark.

| True positives, model docs flagged | 7 | 7 |
| False negatives, model docs passed | 56 | 56 |

| F1 | 19.2% | 19.2% |
| Accuracy | 51.2% | 51.2% |

A trivial gate that passes every file would score 47.9% accuracy. The current gate scores 51.2%. It catches 7 model docs and rejects 3 human docs.

## Conclusion

On this corpus, the gate flags 7 of 63 model docs and 3 of 58 human docs. Precision is 70.0%, recall is 11.1%, F1 is 19.2%, false positive rate is 5.2%.

The gate catches visible patterns. It misses most polished model prose, and it rejects human docs that use the same patterns.

This is a style gate, not an authorship detector. The result is a calibration baseline, not a product claim.

## Why

- The model docs that fail contain visible flags: arrow cascade, contrastive negation, em dash, "here's why" opener, low burstiness, monotonous triplet, zombie words.
- The model docs that pass have low flag density.
- The three human false positives use the same visible patterns: arrow cascade, em dash, monotonous triplet.
- Prose-only preprocessing does not change the result.

## False negatives

56 of 63 model docs passed. They had low hard-flag density. The 7 that failed are counted as true positives in the results table.

## Limits

- The corpus is small: 58 human, 63 model. Treat the numbers as a direction, not a benchmark.
- Human docs may carry AI edits.
- Model docs are model rewrites, not a random sample of model output.
- The gate is a style gate, not an authorship detector.
- Prose-only is a preprocessing prototype here, not a shipped flag.
- English markdown only.
- The source corpus is private, so the report is not reproducible from this repository alone.

## What to change

1. Keep the density rule. It removed the human false positives.
2. Add a new signal for polished model prose. CV and the current regex list are not enough.
3. Expand the corpus to 100 human and 100 model docs, matched by topic and length.
4. Test a semantic layer for restatement and unsupported claims.
5. Do not market the gate as an AI detector. Market it as a style gate.
